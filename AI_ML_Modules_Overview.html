Team Reference — AI / ML Track

AI/ML Modules — Rooftop Solar Assessment

Three independently ownable modules. Each has a clear Phase 1 scope (what ships in the MVP) and a Phase 3 scope (what gets added once the product is proven).

Roof Detection→ Obstacle Detection→ Shading Analysis
Read this first: none of these three modules require a trained ML model to ship Phase 1. Phase 1 is about clean API integration and good manual-input UX — real model training is deliberately deferred to Phase 3, once the product is proven and worth the investment.
1

Roof Detection & Segmentation

Given a satellite/aerial image of a building, output the roof boundary as a polygon, roof shape, sections, and orientation.

Ship Phase 1 via API wrap

Aerial image tile + building footprint (from Google Solar API or building dataset)

Roof polygon (GeoJSON), roof section count, orientation, confidence score

Don't build this from scratch — wrap Google Solar API's roof segment output. This module's real job initially is normalizing that data into your internal format, not training a model.

Fine-tune a segmentation model (e.g. Segment Anything or a U-Net variant) on labeled rooftop imagery datasets.

Python PyTorch / TensorFlow (Phase 3 only) OpenCV

Someone comfortable with image segmentation concepts, or just strong Python + API integration for Phase 1.

2

Obstacle Detection & Classification

Given the roof image/area, detect and classify objects on it — water tanks, HVAC units, chimneys, existing solar panels, vents, antennas — each with a bounding polygon and a confidence score.

Highest ML complexity

Cropped roof image (from Module 1's boundary)

List of obstacle objects: { type, polygon, confidence }

No model at all — this module is just the manual-entry API (customer draws + labels). It's an "AI module" in name only for Phase 1, which is intentional: it satisfies the "never trust blindly" requirement without CV risk.

Object detection model (YOLOv8 or similar) trained/fine-tuned on labeled rooftop object datasets, or a commercial rooftop-AI vendor API as a shortcut.

Python YOLO / Detectron2 (Phase 3 only) Label Studio (dataset labeling)

This is the module where real ML experience matters most, if you go custom. If nobody on the team has trained a detection model before, this is the one phase worth budgeting for a specialist or a vendor API instead.

3

Shading & Roof Condition Analysis

Identifies things that don't block installation but affect performance — trees, neighboring building shadows — and, where 3D/elevation data is available, estimates roof pitch.

Lowest priority — do last

Wider-area satellite image (not just the roof crop), elevation data if available (Digital Surface Model)

Shading risk score per roof section, pitch/azimuth estimate — or an explicit "could not be determined" flag, never invented

Skip entirely, or just surface whatever Google Solar API already gives you (it includes some shading/sunshine hours data for covered regions).

Tree/vegetation segmentation + simple shadow-casting geometry based on sun position and neighboring building heights.

Python GeoPandas / Shapely Solar API Data Layers (elevation)

Lower priority — genuinely leave this for last, since it affects energy estimates, not installability, so it doesn't block a working MVP.
